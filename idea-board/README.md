# Idea Board

A private kanban board for ideas, built as a claude.ai artifact.

- Each idea is a sticky note with a written brief (problem, idea, decisions, open questions, next step), so you can pick it up weeks later without rereading the chat it came from.
- Claude adds ideas and writes briefs from any chat. Just say "add this to my Idea Board".
- On the board you can drag notes between columns, edit column, tags and link, delete ideas, and set column colours.
- Open a note and tap **New chat** to continue the idea in a fresh chat, with the brief as the starting point.
- Works on phone and desktop, in light and dark mode. Only you can see it.

## Setup

1. In a new Claude chat, attach `idea-board.html` and send:
   > Publish this as an artifact with private storage, exactly as the note at the top of the file says.
2. Open the board and tap **Set up board**.

## Use

- **Add:** "Add this to my Idea Board" (paste the board's link the first few times).
- **Pick up:** "Pick up #3 from my Idea Board", or open the note and tap **New chat**.
- **Update:** "Rewrite #3's brief with what we decided today".

Requires a claude.ai account where Claude can publish artifacts with storage.
